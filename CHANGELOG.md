# Changelog

## 0.1.0 - 2026-07-01

First public preview release.

- Published `@litsquare/stage` with the host-agnostic runner, browser preview host, render-host bridge, timing helpers, and audio helpers.
- Published `@litsquare/stage-react` with React provider and hooks for runner-driven views.
- Published `@litsquare/stage-protocol` with shared project config, render request, job state, artifact, diagnostic, and MCP contract types.
- Added workspace examples for basic DOM and React-based stage projects.
- Added public documentation for deterministic frame-derived motion, project anatomy, rendering boundaries, and release operations.
