# Security Policy

## Supported Versions

The current public release line is `0.1.x`.

## Reporting A Vulnerability

Report security issues privately through GitHub security advisories for `thierryc/litsquare-stage`.

Do not open a public issue for suspected vulnerabilities. Include:

- Affected package and version.
- Reproduction steps or proof of concept.
- Expected impact.
- Any relevant environment details.

## Scope

This public repository contains the LitSquare Stage runtime, React bindings, and protocol types. Renderer hosts, deployment infrastructure, credentials, and private capture services are outside this repository's public package scope.
